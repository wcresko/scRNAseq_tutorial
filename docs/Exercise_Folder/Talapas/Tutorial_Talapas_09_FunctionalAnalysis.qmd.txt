## About this tutorial

Take the per-cell-type DE table written by [Talapas 08](Tutorial_Talapas_08_Pseudobulk_DE.html) (`nsclc_pseudobulk_de.csv`) and run two of the most common downstream enrichment analyses with `clusterProfiler`:

1.  **GO over-representation** (Biological Process) on the significant-DE gene set per cell type
2.  **GSEA** on a `log2FoldChange`-ranked list per cell type

Outputs land in `../objects/functional/GO_BP_<celltype>.csv` and `GSEA_BP_<celltype>.csv`.

The executable script is **[`09_functional.R`](scripts/09_functional.R)**. Submit with:

```bash
sbatch --job-name=fa --time=02:00:00 --mem=32G run_rscript.sbatch 09_functional.R
```

## Code (mirror of the script)

```{r}
#| label: setup
library(tidyverse)
library(clusterProfiler)
library(org.Hs.eg.db)

de <- read_csv("../objects/nsclc_pseudobulk_de.csv")
```

```{r}
#| label: enrich
ego_one <- function(de_ct) {
  sig <- de_ct |> filter(padj < 0.05, abs(log2FoldChange) > 1) |> pull(gene)
  if (length(sig) < 10) return(NULL)
  enrichGO(gene = sig, OrgDb = org.Hs.eg.db, keyType = "SYMBOL",
           ont = "BP", pAdjustMethod = "BH", qvalueCutoff = 0.05)
}
```

```{r}
#| label: gsea
gsea_one <- function(de_ct) {
  rk <- de_ct |> arrange(desc(log2FoldChange))
  ranks <- setNames(rk$log2FoldChange, rk$gene)
  gseGO(ranks, OrgDb = org.Hs.eg.db, keyType = "SYMBOL", ont = "BP",
        pAdjustMethod = "BH")
}
```

::: {.callout-important title="Think about it"}
GO enrichment and GSEA disagree on which terms are top for the same cell type. Why?

<details>
<summary>Show answer</summary>

**Different inputs, different statistics.** Over-representation uses a *cut* gene list (padj + LFC threshold) and asks "is this list enriched in pathway X relative to background?" — a hypergeometric test. GSEA uses the *full ranked list* (no cutoff) and asks "does pathway X concentrate at the ranking extremes?" — a Kolmogorov–Smirnov-style running enrichment. They reward different signals: ORA finds pathways where *many* genes pass threshold; GSEA finds pathways where *many genes shift slightly in the same direction* even if few individually pass FDR.

</details>
:::
